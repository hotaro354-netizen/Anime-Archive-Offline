# دستیار آفلاین Anime Archive — نسخهٔ آزمایشی

## فایل‌ها
- `index.html`: رابط چت و موتور سبک تشخیص سؤال
- `data/anime.json`: بانک اطلاعاتی نمونه
- `sw.js`: ذخیرهٔ فایل‌های اصلی برای بازشدن آفلاین پس از بارگذاری اولیه
- `manifest.webmanifest`: تنظیمات نصب به‌صورت وب‌اپ

## اجرا
این پروژه برای میزبانی استاتیک مثل GitHub Pages ساخته شده است. فایل‌ها را با همین ساختار در یک مخزن یا پوشهٔ سایت قرار بده و از طریق HTTPS باز کن. بازکردن مستقیم `index.html` از فایل‌منیجر اندروید ممکن است به‌دلیل محدودیت مرورگر در خواندن JSON و Service Worker کار نکند.

## تست آفلاین
1. یک بار سایت را با اینترنت باز کن و صبر کن تا وضعیت «بانک آماده» دیده شود.
2. همان صفحه را ببند و دوباره باز کن.
3. اینترنت را قطع کن و تست کن. مرورگر ممکن است برای اولین بار نصب/ذخیره‌سازی را به‌درستی کامل نکرده باشد؛ در آن صورت با اینترنت دوباره باز کن.

## نکته‌های مهم
- داده‌ها فعلاً نمونه‌اند و پوشش کامل انیمه‌ها را ندارند.
- این نسخه مدل زبانی بزرگ نیست؛ موتور سبک تطبیق سؤال با داده‌های ثبت‌شده است.
- پیشنهادهای اصلاحی در `localStorage` همان مرورگر می‌مانند. با «خروجی اصلاحات» می‌توانی فایل JSON بگیری.
- Service Worker به HTTPS یا localhost نیاز دارد؛ این نسخه برای اجرای عادی از مسیر `file://` طراحی نشده.
- پیش از انتشار عمومی، تعداد فصل‌ها/قسمت‌های متغیر و داده‌های تازه باید بازبینی شوند.
